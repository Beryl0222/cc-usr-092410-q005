# 数字文化展项立项台

本仓库记录该项目已确认的领域对象、事件名称和基础校验方式，便于不同系统交换一致的数据。当前基线覆盖策展命题、学术来源、组件复用，以及**互动组件退役传播**的完整处置链路。

## 资料范围

- `contracts/domain.schema.json`：领域事件信封、聚合类型与事件名称。
- `data/sample.json`：一条用于本地联调的中文信封样例。
- `data/sample-stream.jsonl`：由脚本生成、可复现的退役全流程事件流。
- `src/`：
  - `validator.js`：事件信封的最小校验；
  - `store.js`：append-only JSONL 事件存储（event_id 唯一、聚合版本连续、全局 seq 单调）；
  - `registry.js`：策展命题之外的组件谱系登记（组件、版本发布、展项部署、来源撤回）与目录投影；
  - `retirement.js`：组件退役领域服务（冻结、阻断、方案、双签、决定、回执、调查、批次）；
  - `lineage.js`：从任一上线版本追溯谱系、证据、签署、决定与执行的只读模型；
  - `domain.ts`：事件与载荷的 TypeScript 类型。
- `scripts/generate-sample.js`：生成确定性样例事件流。
- `tests/`：信封约定与退役不变量测试。

记录一经接收，标识、发生时间与版本不得原地改写；更正使用新的后继记录。个人、机构及商业敏感信息仅向履行职责所需的调用方开放。

## 组件退役生命周期

```
发起人选定组件版本与原因（RETIREMENT_INITIATED）
        │  系统即时冻结当时命中且可处理的部署范围（DEPLOYMENT_SCOPE_FROZEN）
        │  受前批未确认动作影响的部署进入 excluded，本批不得处理
        ├─（紧急）EMERGENCY_BLOCK_ISSUED：先阻断命中组件，无须等待签署
        ▼
项目负责人逐展项提交方案（REPLACEMENT_PLAN_SUBMITTED）
   暂停 PAUSE / 替换 REPLACE / 授权不受影响·补充说明 ADDENDUM
        ▼
学术签署 + 法务签署（两条 RETIREMENT_SIGNED，缺一不成决定）
        ▼
双签齐备 → 逐展项决定（RETIREMENT_ITEM_DECIDED）
        ▼
渠道回执确认实际执行（EXECUTION_RECEIPT_RECORDED）
   └─ 同回执号异义 → RECEIPT_CONFLICT_FLAGGED 调查项，不覆盖、不误报
批次允许部分关闭（RETIREMENT_BATCH_CLOSED），未完成项保留自身进度
```

### 关键不变量

1. **冻结即快照**：发起退役时按当时仍运行的部署生成处置项；冻结后新增、下线的部署不改变本批范围。
2. **批次范围互斥**：前批存在未完成处置项（含调查中）的「组件｜展项｜渠道」范围，后批只能整体排除并记录阻断批次；即使同展项已升级到新版本也不例外。
3. **紧急阻断先行**：可在签署前阻断命中组件；阻断与后续事件都只追加，旧发布记录和已确认回执永不改写。
4. **双签决定**：方案须学术、法务分别签署；签署后方案不可更换，单签不产生决定。
5. **回执一致性**：执行动作须与决定一致、渠道须与冻结部署一致；同一回执号上报不同内容（或指向另一处置项）只开立调查项，首次记录保持正本。
6. **部分成功**：批次关闭时完成项收口，未完成项保留各自阶段（如已决定待回执），可随时继续。
7. **重启续跑**：服务状态完全由事件流重放，重启后从各展项既有进度继续，seq 与 event_id 不变。
8. **谱系可追**：从任一上线 `release_id` 可沿 `parent_release_id` 追版本谱系，并查到各部署的证据变化（如 `SOURCE_WITHDRAWN`）、紧急阻断、方案、双签、决定、回执与调查结论。

`tests/retirement.test.js` 中「两次相邻退役交错发生」用例构造了三批退役交错推进的事件流，断言冻结/排除范围不被后续动作回溯改写、全局 seq 单调、聚合版本连续。

## 本地检查

```bash
npm run sample   # 重新生成 data/sample-stream.jsonl（确定性输出）
npm test         # 信封约定 + 退役全部不变量
npm run build    # 全部源码语法检查
```

这些命令可在单个 Linux 应用容器内执行，不需要另行启动外部服务；事件存储默认 JSONL 文件，测试使用临时文件或内存模式。
